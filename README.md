Hackathon ONE G9 - TechMind – Organización Inteligente del Conocimiento Técnico 
Repositorio Equipo G9-LATAM-Team 61 para la Hackathon de ONE (Alura + Oracle).

Objetivo del Proyecto
Profesionales y estudiantes de tecnología consumen diariamente una gran cantidad de contenido técnico, lo que dificulta organizar, localizar y reutilizar esta información posteriormente.

Nuestro objetivo es crear una solución impulsada por Inteligencia Artificial que permita la organización inteligente de contenido técnico.

La aplicación recibe textos técnicos (artículos, documentación, anotaciones, etc.) y, mediante técnicas de procesamiento de lenguaje natural (NLP) y Ciencia de Datos, extrae información relevante, clasificando el contenido automáticamente.
